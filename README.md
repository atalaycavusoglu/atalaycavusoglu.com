# atalaycavusoglu.com

My personal one-page profile site — live at **[atalaycavusoglu.com](https://atalaycavusoglu.com)**.

- Plain HTML, CSS and JavaScript in a single `index.html`, no build step
- Turkish / English toggle (remembers the visitor's choice)
- Scroll-driven animations, typewriter headline, animated counters and marquee
- Built-in rule-based chat assistant that answers quick questions about me
- Responsive for phones and tablets; respects `prefers-reduced-motion`
- Hosted on Vercel

## Run locally

```sh
python -m http.server 5500
```

Then open http://127.0.0.1:5500.
